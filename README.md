# 🌍 AI Translator

An AI-powered translation application built with Streamlit, LangChain, and Groq.

## Features

- Translate text between multiple languages
- Simple and user-friendly interface
- Powered by AI using Large Language Models (LLMs)
- Fast and accurate translations

## Technologies Used

- Python
- Streamlit
- LangChain
- Groq API

## Installation

pip install -r requirements.txt

streamlit run app.py
